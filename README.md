# 📊 voice-clone-evaluator

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Domain: Speech AI](https://img.shields.io/badge/Domain-Voice%20Cloning-orange.svg)](https://github.com/MobileConduit)

A benchmark utility for calculating acoustic energy, duration ratio, and spectral consistency between original reference voice samples and AI-synthesized clones.

```bash
python evaluator.py --ref ground_truth.wav --synth cloned_xtts.wav
```
